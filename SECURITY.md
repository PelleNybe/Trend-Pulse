## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability in this project, please do not open a public issue. Instead, report it privately by creating a GitHub Security Advisory (`Security` -> `Advisories` -> `New draft security advisory`) in this repository.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If a fix is needed, we will provide you with a timeline.
