# Support Guidelines

## Need Help?

If you need help using this project, you can get support through the following channels:

### 1. Read the Documentation
Before asking a question, please check the [README.md](README.md) and any other provided documentation.

### 2. Search Existing Issues
Your question may have already been asked and answered. Please search the [issue tracker](https://github.com/PelleNybe/Trend-Pulse/issues) before opening a new issue.

### 3. Open an Issue
If you found a bug or have a feature request, please open an issue in the issue tracker. Provide as much context as possible, including steps to reproduce the bug.

### 4. Community Discussions
For general questions, "how-to" scenarios, and sharing ideas, you can use GitHub Discussions or open an issue labeled `question`.
